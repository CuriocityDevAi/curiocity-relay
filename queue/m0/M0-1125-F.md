- 폴더 탭 형태로: 활성 탭 = 아래 설정 패널과 같은 배경색 + 같은 테두리로 이어짐, 활성 탭 아래쪽 경계선은 끊겨 패널로 열림. 비활성 탭 = 패널보다 어두운/옅은 배경, 패널 위 경계선이 그대로 보임.
- 설정 패널 전체(탭에 속한 항목들)를 테두리·배경이 있는 하나의 상자로 감싼다. 현재는 탭 아래 항목이 페이지 배경에 그냥 떠 있음.
- 활성 탭에 강조색 표시(위쪽 2px 강조선 등) — 색은 semantic 토큰만(--accent 등), raw hex 금지.
- 다크·라이트 테마 둘 다. 키보드 이동(←/→)·aria(role=tablist/tab/tabpanel, aria-selected, aria-controls) 유지.
R2 닉네임 영숫자 (Kyu 원문: "alphanumeric으로 고쳐서 숫자도 반영가능하도록")
- 규칙: 대문자 영문+숫자 2~4자, 첫 글자는 영문 (정규식 ^[A-Z][A-Z0-9]{1,3}$). 소문자 입력은 자동 대문자.
- 닉네임이 숫자로 끝나면 주문번호에 하이픈을 넣는다: PIM3 → PIM3-26B1000 (끝 숫자와 연도 26 이 붙어 PIM326B… 로 읽히는 것 방지). 영문으로 끝나는 닉네임(PIM)은 기존 형식 PIM26B1000 그대로.
