4. xendit 웹훅 paid/capture 성공 시 해당 tender 의 `metadata.tenders[idx].status="captured"` patch (§3-8) — 매칭 키 = 그 tender 의 payment_request_id / payment_collection. 중간 tender paid 는 영수증 mint·draft→order 전환 없음(기존 is_complete 규칙 유지)을 테스트로 확인.
5. QRIS 만료/실패(웹훅 expired/failed 가 오는 경우) → status expired/failed 로 patch (웹훅 이벤트가 없으면 해당 부분은 "미구현·이유"로 리포트).

   b) 1차 QRIS PENDING 중 2차 요청 → 409 `qris_pending_cannot_split_next` → paid 뒤 2차 CASH → 완료
   c) 양쪽 QRIS 50k+50k 완결
