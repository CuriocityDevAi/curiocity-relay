## [REQ]
1. **필드 확정 (오케가 Xendit 공식 문서로 확인)**: v3 Payments API 웹훅 payment 객체에 `payment_details.receipt_id` = "Receipt reference number communicated to the end user by their payment method provider for this specific payment" (docs.xendit.co/apidocs/payment-webhook-notification). Xendit 도움말의 QRIS 결제 증빙 기준도 콜백 payload 의 `receipt_id` 를 손님 증빙 번호로 안내.
   → `qrisRrn` 추출 1순위 = `data.payment_details.receipt_id`. AH 의 추측 후보 경로들은 **삭제**(근거 없는 경로 유지 금지). 단 `payment_details.rrn` 하나만 2순위로 남겨도 됨(근거 주석).
2. 필드명 `qris_rrn` → 의미가 receipt_id 이므로 metadata/snapshot 키를 `qris_receipt_id` 로 이름 정리(기존 `issuer_rrn`·`reference_no` 호환 유지). 폴백 순서: receipt_id → Xendit `payment_id`(라벨 "Xendit ID" 용 `xendit_payment_id`) → 기존 reference_no.
3. 단위 테스트를 공식 필드 기준으로 갱신(receipt_id 있음 / 없음→payment_id / 둘 다 없음).
