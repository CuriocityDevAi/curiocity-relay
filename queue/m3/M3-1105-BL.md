## 서버 계약 (main 에 머지됨 · #228 #229 #231)
- QR 생성: 기존 tenders POST 에 provider QRIS → 응답 `qr_string · expires_at · payment_request_id` (자세히: relay m0/M0-1105-BC-report.md)
- 상태: `GET /admin/pos/orders/:id/qris-status` · 재생성: `POST /admin/pos/orders/:id/qris-regenerate`
- 나눠 결제 + QRIS = 400 `qris_split_not_supported`
- 키 미설정 = 400 `xendit_not_configured`
- QRIS 환불: return method='qris' · 거부 시 400 `qris_refund_rejected` + fallback cash (relay m0/M0-1105-BD-report.md)
