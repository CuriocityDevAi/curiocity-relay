[REQ]
목표: 맥북(허브 5 + CI 러너 4, 메모리 15.9GB/16GB)에서 CI 를 아이맥으로 옮겨 맥북 메모리를 허브에 돌려준다. 한 달 뒤 맥미니가 오면 같은 스크립트를 다시 돌려 역할을 옮길 수 있어야 한다.
1. 한 번 실행으로 CI 기계가 완성되는 idempotent 스크립트(여러 번 돌려도 안전). 기계 이름이 아니라 역할(role) 로 설정: ROLE=ci-box.
2. 설치 항목: Homebrew · Node(현 CI 와 같은 버전) · pnpm(같은 버전) · Postgres 16(현 맥북 CI 와 같은 DB명·유저·포트, 테스트 전용) · Playwright 브라우저 · OrbStack(Docker — docker-build-pr 를 클라우드 대신 여기서 돌릴 수 있게) · gh CLI · Tailscale.
3. GitHub self-hosted 러너: storeport heavy/light · agilo-medusa-pos-fork heavy/light 를 **지금 맥북 러너와 같은 라벨**로 등록 → 워크플로 파일 수정 없이 빈 쪽 기계가 잡게 한다. 러너 이름 = <role>-<repo>-<heavy|light>-<호스트짧은이름>. launchd 서비스로 부팅 시 자동 시작.
4. 등록 토큰은 스크립트가 터미널에서 Kyu 에게 입력받는다(read -s). 토큰을 파일·로그·커밋에 남기지 말 것. 토큰 얻는 방법(GitHub 저장소 Settings → Actions → Runners → New self-hosted runner 화면의 토큰)을 README 에 쉬운 말로.
5. 상시 가동: pmset 로 잠자기 끔(디스플레이만 꺼짐) · 정전 후 자동 켜짐 · Remote Login(SSH) 안내.
6. 상태 보고: 아이맥 러너도 relay status/runners 에 보이게(기존 ci-watch·heartbeat 가 러너 목록을 GitHub API 로 읽으면 자동 — 확인만, 필요 시 최소 수정).
7. 이관 2단계 문서: ① 아이맥 러너 추가(맥북 러너 유지, 병행 1~2일) ② 안정되면 맥북 러너 끄는 명령(launchd unload) — 끄는 건 Kyu 가 판단.
