## [REQ]

2. `on: workflow_run`(ci.yml 의 workflow name · types completed) → 해당 run 의 PR 을 찾아 job 이름 / 결과(✅❌⏭) / 소요 / 실패 job 링크 표를 **PR 코멘트 1개로 upsert**(숨은 마커 `<!-- ci-summary -->` · 새 run 마다 같은 코멘트 갱신 · 커밋 sha 표기).
