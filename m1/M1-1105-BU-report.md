## 계획 요약

**현 상태**: 고객 조회 화면(`app/customer-lookup.tsx`) 이미 있음. 이메일 기반 검색만 · phone 조회 없음 · 포인트 코드 0줄 · WA 발송 없음(타입만).

**라운드 순서**:
- R0: 고객 phone 검색 강화 + 동의 기록 (서버·앱 각 30min)
- R1: 포인트 원장 모듈 서버 + 앱 잔액 표시/사용 (Q8 결정 후)
- R2: 환불 시 포인트 회수 (서버·앱)
- R3: WA 영수증 발송 (K5 Meta 번호 승인 후)

**포인트 사용 방식**: 선할인(A안) 채택 — split-tender max 2 제약 때문에 포인트 tender 추가 불가.
