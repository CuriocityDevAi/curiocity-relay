## 심문 (3문항)

### Q1. 승격 옵션 채택?

- **(a)** A · 단말 직접 (실시간 · 계약 부담 최대 · Native 필수)
- **(b)** B · 사후 API (T+1 · 계약 중간 · 단말 무접촉)
- **(c)** C · QRIS 우선 · Card 는 별건 (Aggregator 계약 1개로 QRIS 실시간 확보 · Card 는 후속 B/A)
- **(d)** 승격 보류 · 현재 NullAdapter (앱 수기) 유지 · EDC 별건 착수 시 재심문

### Q2. Q1=(c) 채택 시 · QRIS Aggregator 우선순위?

- **(가)** Xendit (인도네시아 시장 대표 · SDK 성숙 · 요금 다소 높음)
- **(나)** Midtrans (Gojek 계열 · QRIS + Card 겸업 가능)
- **(다)** Doku (오래된 사업자 · 대형 매장 위주 · 소규모 매장 fit 낮을 수 있음)
- **(라)** 미정 · 계약 견적 비교 별건

### Q3. Q1=(a) or (b) 채택 시 · Card 매입사 우선순위?

- **(가)** BCA (인니 최대 은행 · 폐쇄적 API · 계약 난이도 상)
- **(나)** Mandiri (개방적 · SNAP 표준 참여 · 계약 난이도 중)
- **(다)** OCBC / CIMB / 기타 · Kyu 매장 실사용 은행 기준
