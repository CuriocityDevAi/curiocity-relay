## 확정 매핑 — 두 갈래 상태의 조합
- 결제 상태(POS가 정함): 담는 중(Sell/Cart/Checkout) → 결제수단 화면 → 결제 완료 / 실패·취소
- 손님 상태(손님이 정함): 없음 → 번호 입력 중 → (첫 방문) → 확인 대기 → 확인됨 / 건너뜀
- CD 화면 = 두 상태의 조합. 결제 상태 변화가 손님 진행 화면(입력·첫방문·확인)을 덮지 않는다.

| POS 단계 | 손님: 번호 없음 | 손님: 입력·첫방문·확인 중 | 손님: 확인 완료 |
|---|---|---|---|
| Sell·Cart·Checkout | ① 주문내역 (입력 버튼 없음) | — | — |
| 결제수단 화면 | ① 주문내역 + 입력 버튼 활성 | 우 2/3: ②/첫방문/③ · 좌 1/3: 화면명(QRIS 면 QR) | 우: "확인됐어요 · 결제 대기" |
| 결제 완료 | 영수증 전체 → 3초 → 영수증 좌 1/3 + 우 2/3 ② (경우 1) | 좌 1/3 에 영수증 출력 · 우는 진행 유지 | ④ 포인트 적립 (좌 영수증) |
| 결제 실패·취소 | ① 주문내역 복귀 | 진행 유지 | ④ 자리에 결제 실패 안내 |

POS 번호 칩: `입력 중…` → `확인 대기 0813…` → `✓ 0813…480 · 포인트 N`

확인 화면: OK 후 같은 우 2/3 자리에서 키패드 → 확인 카드(번호 전체 · 현재 포인트 · [맞아요] 큰 버튼 · [번호 수정])
