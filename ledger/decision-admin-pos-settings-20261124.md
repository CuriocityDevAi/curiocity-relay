# 결정 — Admin POS Settings 정리 (Kyu 11-24 15:44 · 실기 1부)

원문: "1부. Order number 가 새로 생겼는데, 이렇게 메뉴를 따로 뺄게 아니라, POS Settings 에 하나의 항목중으로 넣는게 맞아보여. 둘째로, Pos Setting 를 눌러보면, 세금 관련된 내용과, Preorder 관련된 내용, Payment Integration 관련 내용들이 막 섞여있는데, 내 생각에는, 이것들을 그룹핑을 해서 정리를 해야할것같아. POS Settings 을 누르면 그 안에서 tab 으로 분리해서 관리하는게 깔끔할것같아. loyalty 같이 현재 POS Setting 밑에 sub menu 로 들어간것은, 내용이 많으므로, 탭으로 관리하지 말고, 현재 POS Settings 와 같은 레벨로 메뉴를 빼는게 맞을듯. 즉, Gift Cards 레벨로. 그나저나 Gift Cards는 현재 필요없는 메뉴같아서, 이것의 원래 용도를 알려주고, 필요없으면 숨기자."

결정(오케 정리): ① Order Numbers → POS Settings 안 탭 ② POS Settings = 탭 구조(기존 항목 그룹핑) ③ Loyalty = POS Settings 하위 → 상위 메뉴(사이드바 1레벨) ④ Gift Cards = 용도 확인 후 미사용이면 사이드바에서 숨김(데이터·모듈 삭제 아님 · 다시 켜기 가능)
