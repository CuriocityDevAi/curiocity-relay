## 확정
1. CI 큐: 풀 4줄(storeport-heavy · storeport-light · fork-heavy · fork-light). 풀 줄 오른쪽 = 대기 칩 + 평균대기(오늘 queued→started). 아랫줄 └ 는 **항상 표시**, 고정 폭 3칸 = **MBP M1 · iMAC M1 · 클라우드** (칸 제목은 구역 제목줄에 1회). 칸 내용 = `⠹ <ID> <분>` / `쉼` / 빨강 `OFF`. 클라우드 다중 실행은 `+N`.
2. 기계 판별 = GitHub job runner_name: `ci-box-*-imac` → iMAC · `curiocity-mac-*`·`Youngkyus-MacBook*` → MBP · 그 외 → 클라우드. 대기 잡은 기계 미정이라 칩으로만.
3. CI 구역 마지막 줄 `오늘 처리` = 기계별 건수 · 평균 실행 분 · 클라우드는 비용 추정.
4. 허브 큐: 허브 줄 오른쪽 끝에 평균대기(오늘 queue→started). └ 는 실행 중일 때만(기존 유지).
5. 경보: 줄에 속한 문제는 그 칸·칩·줄을 **그 자리에서 빨강**(따로 옮겨 적지 않음). 줄에 속하지 않는 경보(러너 오류·git needs_human·rate limit 등)만 **맨 아래 주의 구역**에 한 줄씩. 평소 0줄(제목줄만) → 위쪽 표 위치 불변.
6. 화면 갱신: 전체 지우고 다시 그리기 금지 → 바뀐 칸만 덮어쓰기. 숫자는 고정 폭 오른쪽 정렬. 흘러가는 로그 줄은 본 화면에서 제거(상세 보기로). 스피너만 계속 움직임.
7. 빨강 기준 = decision-ci-watch-tui-layout-20261125 큐 정체 규칙 그대로(HUB/CI 60초 · CLOUD 180초 · OFF 즉시).
