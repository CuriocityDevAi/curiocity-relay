## 규칙
1. 오케 세션 시작 때(현황판 전에) `~/.hub-runner` 폴더 접근을 요청한다 — 접근 승인은 **그 세션에만** 유효하므로 매일 새 창마다 1회. Kyu 는 승인 창에서 한 번 누르면 됨.
2. 감시 틱에서 relay 신호가 이상하면(러너 커밋 5분 이상 없음 · 발부 후 5분 내 started 없음) **Kyu 에게 묻기 전에** 로그를 직접 읽는다: `launchd.err.log` 끝부분 · `<허브>/<ID>.log` · `sleep-events.ndjson`.

4. "relay 에 안 보임" ≠ "러너 멈춤". 판정 순서 = 맥 응답 여부 → 러너 로그 → 그 다음에 경보.
5. 숨김 폴더라 앱의 Add folder 창에는 안 보인다 — 오케가 요청을 보내 Kyu 가 승인하는 방식이 기본(직접 고를 땐 파일 창에서 Cmd+Shift+. 로 숨김 표시).
