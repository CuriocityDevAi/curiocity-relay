## 확정 규칙 (현금 빠른 버튼)
- 받은 금액 시작값 = 결제금액(그대로 두면 정확히 받음).
- 버튼 A = ceil(결제금액 / 50,000) × 50,000 · 버튼 B = ceil(결제금액 / 100,000) × 100,000 — **멱등**(여러 번 눌러도 같은 값). 누적 아님.
- 오케 표기 결정: 버튼 글자 = 눌렀을 때 들어갈 **실제 금액**(예 68,200 → "IDR 100,000") · 두 버튼 결과가 같으면 하나만 표시 · 결제금액이 이미 그 배수면(예 100,000) 그 버튼 숨김(Exact 와 같아서). 기존 고정 IDR 50,000/100,000 버튼·Exact 버튼 제거.
- 특정 금액은 Custom amount 직접 입력 · 받은 금액 < 결제금액이면 Process payment 꺼짐 유지.
