## 결정
| 항목 | 내용 |
|---|---|
| 기본 | 무거운 검사는 Mac 실행기(`curiocity-mac`) · 가벼운 검사는 Mac light 실행기(`curiocity-mac-light`) |
| 넘기기 조건 | Mac 무거운 실행기가 바쁨 **AND** PR 이 ready(draft 아님) → GitHub-hosted Linux |
| 하루 할당 | **5건/일**(WIB 날짜 기준) · 건당 약 $0.24 · 월 $60 지출 한도는 그대로 최종 안전장치 |
| 6건째 | 자동으로 넘기지 않고 Mac 대기 + **Kyu 에게 문의**("오늘 +5건 추가할까?") |
| 추가 | Kyu 승인 시 **그날만 +5건** (여러 번 가능 · 날짜 바뀌면 리셋) |

## 구현 메모 (M2 · #369 머지 뒤 발부)
- 배차 잡(light 실행기 · 수 초): 무거운 실행기 busy 조회 → runs-on 결정 · 오늘 클라우드 사용 건수 카운트.
- 추가 할당 신호 = relay `ci/cloud-quota/<YYYY-MM-DD>.json` `{ "extra": 5 * n }` (공개 raw 로 읽음 · 오케가 Kyu 승인 받으면 커밋).
- 6건째 문의 신호 = PR 라벨 `ci-cloud-quota-exceeded` (오케 감시 틱이 GitHub 에서 읽고 Kyu 에게 문의).
- 실패해도 안전: 배차 잡 오류 → 기본값 로컬 대기.
