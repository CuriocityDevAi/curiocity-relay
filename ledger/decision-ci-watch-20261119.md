## 원인 (오케 자기 진단)
1. 감지 수단 없음: 오케 GitHub 연결은 check-runs/actions API 403 → 감시 틱이 CI 를 아예 안 봄. 클라우드 R0(R0C-1119-G·H)를 따로 띄웠을 때만 알았음.
2. 자동 조치 없음: overflow(11-18 결정)를 구현 발부하지 않음 → 맥 heavy 러너 1대가 혼자 받음.
3. 줄 오염·낭비 방치: 머지된 PR run · 원격 캐시 11분/job · step timeout 없음.
4. 테스트 안내 묶음: POS(fork) 는 CI 와 무관하게 머지됐는데 오케가 손님 화면과 묶으려고 실기 안내를 미룸.
