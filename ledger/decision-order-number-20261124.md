# 결정 — 긴 Order 번호 채번 (Kyu 11-24 11:15)

원문: "A 안의 문제는 사람들이 우리 매장에 몇개의 매출이 있었는지를 너무 쉽게 알수 있다는거야. 아 오늘 42번째 매출이구나~ 라고 알리고 싶진 않아서, 월별로 했으면해. PIM26+1자리 달을 의미하는 (1, 2, 3 , 4, 5, 6, 7, 8, 9,  O, N, D) 알파뉴메릭 + 4자리 숫자. 즉, PIM2620012 : PIM 매장의 26년도 2월의 12번째 매출. 이러려면, 매장이 여러개인경우, 매장의 nick name 을 어드민에서 관리하는 화면이 있어야겠다."

형식: `{매장닉네임}{YY}{월1자리}{월별 일련 4자리}` — 예 PIM2620012
