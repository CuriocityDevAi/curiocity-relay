## 확정 규칙
- 형식 `{매장닉네임}{YY}{월}{일련}` · 월 = 1~9, A(10) B(11) C(12) · 예 PIM26B1000 = PIM 매장 2026년 11월 첫 주문
- 일련: 매달 시작번호(기본 1000 · Admin 설정)부터 1씩 증가 · 4자리 0 채움 · 9999 초과 시 5자리
- 매장 닉네임 Admin: 영문 대문자 2~4자 · 중복 금지 · 그 매장 첫 번호 발급 후 잠금
- (오케 결정) 시작번호 변경은 **다음 달부터** 적용(이번 달 번호 충돌 방지) · 월 경계 WIB · 취소 주문도 번호 유지 · 닉네임 없는 매장은 주문 실패시키지 않고 기존 display_id 로 표시 + Admin 경고 · 기존 주문 백필 없음
