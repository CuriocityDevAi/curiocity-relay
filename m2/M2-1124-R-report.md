## 3. 카드별 정보 출처표

| 칸 | 판정 근거 | 로컬 확정 | 로컬 예측 | GitHub 필요 |
|---|---|---|---|---|
| **큐** | `queue/<hub>/<ID>.md` 존재 여부 | ✅ | — | — |
| **허브작업** | `status/claims/<ID>.json` 존재 + `status/runners/<hub>.json` busy 플래그 | ✅ | — | — |
| **리포트** | `<hub>/<ID>-report.md` 존재 여부 (`~/.hub-runner/reports/`) | ✅ | — | — |
| **PR** | `status/pipeline/<ID>.jsonl` 의 `artifact` 이벤트 (`pr_number` 필드) · 러너가 `gh pr list` 로 결정적 수집 후 jsonl에 기록 | ✅ | — | — |
| **CI대기** | `ci_pending` 이벤트가 jsonl 에 있으면 로컬 확정 · PR push 직후 `ci_pending` 미착 → "대기 예측" | ✅(이벤트 있을 때) | ✅(PR push 직후 N분 내) | — |
| **CI실행** | `status/runners/all.json` ci.data + 로컬 CI 러너 `_diag` 로그 (`~/.hub-runner/`) | ✅(로컬 러너) | — | △(클라우드 러너만) |
| **CI결과** | 로컬 CI 러너 완료 로그 (`status/ci/<ID>.jsonl`) · `ci_result` 이벤트 | ✅(로컬 러너) | — | △(클라우드 러너만) |
| **리뷰** | `status/pipeline/<ID>.jsonl` 의 `review_start`·`review_done` (러너 R0 작업 완료 시 기록) | ✅ | — | △(실제 GitHub approve 여부 확인 필요 시) |
| **머지** | `status/pipeline/<ID>.jsonl` 의 `merged` 이벤트 · 허브 git push 완료 감지 | ✅ | — | — |

**표 요약**:
- 큐·허브작업·리포트·PR·머지 = **완전 로컬 확정**
- CI대기 = 로컬 확정(이벤트 있을 때) + 로컬 예측(이벤트 없을 때)
- CI실행·CI결과 = 로컬 확정(로컬 러너) + GitHub 필요(클라우드 러너)
- 리뷰 = 로컬 확정(착수·완료) + GitHub 선택적(승인 여부)

## 4. GitHub 예측 모델 & 이상 감지 트리거

### 4-1. 예측 흐름

```
PR push 감지
(status/pipeline/<ID>.jsonl 에 artifact.pr_number 등록)
       │
       ▼
"CI 대기 예측" 카드 생성 (ci_pending 이벤트 없을 때)
       │
  N분 경과 ──────── 로컬 CI 러너 작업 시작?
       │                   │ YES → 로컬 확정으로 전환
       │ NO (이상 감지)     │
       ▼
  GitHub 조회 트리거
  (queued? cloud로 넘어갔나? 에러?)
       │
       ├─ GitHub queued 확인 → "CI 대기" 카드 갱신 (클라우드)
       ├─ GitHub in_progress 확인 → "CI 실행" 카드 갱신 (클라우드)
       └─ 아무것도 없음 → "■ CI 미등록 이상" 경보
```

### 4-2. 이상 감지 목록 & 트리거 조건

| 이상 유형 | 트리거 조건 | GitHub 조회 여부 | 주기 상한 |
|---|---|---|---|
| CI 미시작 | PR push 후 로컬 러너 N분 내 미시작 (기본값 N=5분) | ✅ | 1회/이상 |
| CI 장기 대기 | ci_pending 이벤트 후 로컬 러너 M분 내 미시작 (기본값 M=10분) | ✅ | 1회/이상 |
| 클라우드 CI 감지 | 로컬 러너 작업 없는데 PR 열려있음 | ✅ | 5분에 1회 이하 |
| 허브작업 비정상 | 허브작업 칸 체류 > 프롬프트 상한 (상한 초과) | ❌(로컬 판정) | — |
| 리뷰 미완 | review_start 후 P분 이상 review_done 미발생 | ✅(선택적) | 10분에 1회 이하 |
| 큐 적체 | 큐 대기 Q분 초과 (기본값 Q=5분) | ❌(로컬 판정) | — |
| err_tail 반복 | 동일 에러 3회 이상 (ERR_PATTERNS 기존 로직 유지) | ❌(로컬 판정) | — |

**이상 없을 때 GitHub 조회**: 클라우드 한도 확인 + R0 리뷰 상태 → **5분에 1회 이하** (GH_IDLE_REFRESH_MS 유지)
