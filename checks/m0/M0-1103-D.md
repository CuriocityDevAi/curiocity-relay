## 요지

M0-1103-D · 옛 draft order ID 자가 복구 핫픽스 (fork PR #12).

**뿌리**: 저장된 옛 ID 가 stale (404 or "is not a draft order") 응답 시 자가 복구 경로 없음 → M0-1012-A sequential-orders 재실기 ✗.
